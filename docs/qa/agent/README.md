# Agent transcript artifacts (QA)

This directory holds **agent transcript artifacts** produced by QA runs — readable
records of the product agent's (Ember's) turns as a test exercised them. The
markdown/json run outputs are **gitignored** (regenerated each run); only this
README is committed, matching the retrieval-smoke / RAGAS / regression convention.

## `shopping-journey-*.md` — US-QA-D20 full buyer money-path E2E

Generated by `e2e/tests/shopping-journey.spec.ts` (the `@web` Playwright lane).
As the full buyer journey runs — search/PDP → cart → checkout **approval gate**
→ order placed → order status, plus returns/HITL and the seller dashboard — the
spec records each of Ember's concierge turns into a transcript.

The signature turn is the checkout **approval gate** (ADR-0038): Ember pauses at
the human-in-the-loop `interrupt()` moment, restates exactly what she is about to
do (items · ship-to · payment · total), and only runs the contract two-step
payment (`POST /orders` → `payment-intent` → `payment-confirm`) on **Approve**.
The transcript captures both payment outcomes the journey exercises — the
`captured` happy path and the deterministic `payment_declined` (402) held-order
retry.

- `shopping-journey-<date>.md` — the dated run output (gitignored).
- `shopping-journey-latest.md` — the stable latest pointer (gitignored).

Run it: `cd e2e && npm run e2e:web` (boots the Next app, runs the `@web` lane on
both viewport projects, writes the transcript on completion).

> Today this runs over the ADR-0037 **mock** agent/shop runtime (backend not
> live). At the Day-21 W3 gate the mock handlers proxy the live backend and the
> Approve action is wired to the real agent `interrupt()` resume — the transcript
> shape does not change.
